# 경제금융용어 800선 학습 앱

한국은행 『경제금융용어 800선』(2026)을 외우기 위한 웹앱입니다.
브라우저에서 바로 열리고, 홈 화면에 추가하면 앱처럼 씁니다.

## 기능

- **용어장** — 783개 용어를 검색하고 대분류·소분류·상태·중요·초성으로 걸러 봅니다
- **외움 체크** — 외운 것과 안 외운 것을 직접 표시하고, 중요 표시를 따로 답니다
- **오늘의 학습** — 안 외운 용어 20개를 카드로 넘겨 보고, 끝나면 그 20개로 복습 퀴즈를 풉니다
- **OX 퀴즈** — 반의어 치환·숫자 교란·유사 용어 교차로 함정 문항을 만듭니다
- **용어 맞히기** — 뜻을 보고 4지선다로 고릅니다. 보기는 같은 소분류에서 뽑습니다
- **통계와 백업** — 분야별 진도, 자주 틀린 용어, 기록 내보내기/불러오기

학습 기록은 브라우저에만 저장됩니다. 로그인이 없고, 기록이 서버로 가지 않습니다.
브라우저 데이터를 지우면 사라지니 통계 화면에서 가끔 백업해 두세요.

## 직접 돌려보기

```bash
python -m http.server 8000
# http://localhost:8000
```

`fetch`로 용어 데이터를 읽으므로 `file://`로 열면 동작하지 않습니다.
단일 파일이 필요하면 `python tools/bundle.py`로 `build/econ-terms.html`을 만듭니다.

## 데이터 만들기

```bash
python tools/extract.py    # PDF → build/full.txt
python tools/toc.py        # 목차 → 용어 화이트리스트 789개
python tools/parse.py      # 본문 → 정의 783개
python tools/classify.py   # 카테고리 부여 → data/terms.json
python tools/verify.py     # 검증
```

원본 PDF는 저장소에 포함하지 않습니다. 한국은행에서 내려받아 루트에 두세요.

## 테스트

```bash
python -m unittest discover -s tests -p "test_*.py"   # 46개
node --test                                            # 46개
```

의존성을 설치하지 않습니다. Python은 표준 `unittest`, JS는 Node 내장 테스트 러너를 씁니다.

## 알려진 한계

- 목차 789개 중 **783개**를 추출했습니다. 누락 6개는 PDF 목차 표기 자체가 깨진 항목입니다 (`build/missing.txt`).
- 카테고리는 키워드 규칙으로 붙였고 표본 기준 25~30%가 어긋납니다. 정의 데이터는 원문과 일치합니다.
- OX 퀴즈는 규칙 기반이라 "몰라도 티 나는" 문항이 일부 섞입니다. 전체의 98%가 출제 가능합니다.
