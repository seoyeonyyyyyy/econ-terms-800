# 용어 상세 보강 — 설계 명세

- 작성일: 2026-09-20
- 기반: `2026-09-16-경제금융용어-학습앱-design.md`

## 목적

용어 상세를 읽기 쉽게 만들고, 세 번째 퀴즈 유형을 더한다.
용어 범위는 지금의 783개를 그대로 둔다 (투자론·파생상품 용어는 원본에 없다).

## 1. 전체문 문단 나누기

정의문을 문장 단위로 끊어 2~4문단으로 묶는다. **원문 글자는 하나도 바꾸지 않는다.**

- `def` 안에 `\n\n`을 넣는 방식. CSS가 이미 `white-space: pre-wrap`이라 그대로 렌더링된다.
- 문장 경계는 `다.` `이다.` `한다.` 뒤. 3~4문장마다 한 문단.
- 문단 하나가 400자를 넘으면 그 안에서 한 번 더 끊는다.

## 2. 영문명 표기

용어명 옆에 작은 글씨로 붙인다. **원문에 있는 것만 쓴다. 없으면 비워 둔다.**

- 용어명 괄호 안 약자(`국내총생산(GDP)`)는 풀네임까지 찾아 `GDP · Gross Domestic Product`로 적는다.
- 풀네임은 정의문의 `GDP; Gross Domestic Product` 또는 `Gross Domestic Product(GDP)` 형태에서만 가져온다.
- 용어명 바로 뒤 괄호(`경기(Business Conditions)`)는 그대로 쓴다.
- **정의문 아무 데나 있는 괄호 영문을 가져오지 않는다.** 다른 약어를 집어오는 오류가 난다.

## 3. cf. 용어

상세 하단에 `연관검색어`로 걸린 용어와 그 한 줄 요약을 함께 보여준다.

```
cf. 지급준비제도 — 예금의 일정 비율을 중앙은행에 맡기는 제도
```

탭하면 그 용어로 이동한다. 새 데이터가 필요 없다 — `related`와 `summary`를 쓴다.

## 4. 계산식

정의문에서 `=`가 든 식을 뽑아 `formulas` 배열에 담고, 상세에서 별도 칸으로 보여준다.

- 식을 뽑아낸 뒤 정의문에서는 지운다. 문장 중간이 아니라 독립된 줄일 때만 뽑는다.
- 뽑고 나서 정의문이 조사로 끝나면 되돌린다 (문장을 깨뜨리지 않는다).

## 5. 그래프

그림이 있으면 확실히 쉬워지는 용어에만 인라인 SVG를 붙인다. 10개 내외.

대상: 로렌츠곡선, 래퍼곡선, 필립스곡선, 수익률곡선, 베버리지곡선, J커브효과,
경기(순환), 수요탄력성, 규모의 경제, GDP갭.

- `graph` 필드에 그래프 키를 담고, `js/graphs.js`가 키로 SVG를 그린다.
- 다크모드에서도 읽히도록 색을 CSS 변수로 쓴다.
- 축과 곡선에 이름을 달고, 축 이름 없는 장식용 그림은 그리지 않는다.

## 6. 새 퀴즈 — "옳지 않은 것은?"

원문 문장 4개를 보기로 내되 하나만 틀리게 만든다.

- 정의문에서 30~80자 문장 4개를 고른다. 4개가 안 나오면 출제하지 않는다.
- 그중 하나에 기존 OX의 반의어 치환·숫자 교란을 적용해 틀린 보기로 만든다.
- 보기에서 정답 용어명은 4지선다와 같은 규칙으로 마스킹한다.
- 해설에 원문을 보여준다.

## 검증

`verify.py`에 더한다.

- 문단 나누기로 원문 글자가 바뀌지 않았는가 (`\n` 제거 후 원본과 일치)
- `formulas`를 뽑은 뒤 정의문이 조사로 끝나지 않는가
- `alt`가 용어명·정의 첫머리에서 온 것인가 (엉뚱한 약어가 아닌가)
- 새 퀴즈에서 정답 용어명이 보기에 노출되지 않는가 (전수)
