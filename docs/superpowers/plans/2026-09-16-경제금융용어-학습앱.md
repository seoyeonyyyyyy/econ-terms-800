# 경제금융용어 800선 학습 웹앱 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 한국은행 『경제금융용어 800선』 PDF를 데이터화해, 용어 암기 체크와 퀴즈를 제공하는 오프라인 가능한 웹앱을 만든다.

**Architecture:** 빌드 단계가 없는 정적 웹앱이다. Python 스크립트가 PDF를 한 번 파싱해 `data/terms.json`을 만들고, 브라우저는 그 JSON만 읽는다. 학습 기록은 `localStorage`에 저장하되 `store.js` 한 곳을 통해서만 접근한다. 퀴즈 생성·필터링 같은 순수 로직은 DOM과 분리해 Node로 테스트한다.

**Tech Stack:** Python 3.12 + `unittest` (표준 라이브러리), `pdftotext`, 바닐라 JS ES 모듈, Node 24 내장 `node --test`. **설치할 의존성이 없다.**

**Spec:** `docs/superpowers/specs/2026-09-16-경제금융용어-학습앱-design.md`

## Global Constraints

- 용어 수는 **789개가 목표이되, 딱 맞출 필요는 없다.** 하한 750개만 넘기면 진행한다.
  - 책 제목의 "800선"은 실제 표제어 수가 아니다. 목차 표제어는 789개이고, 그중 53개가
    `간접금융/직접금융`처럼 슬래시로 묶여 있다. 모두 풀면 850개가 된다. 800은 어느 쪽도 아니다.
  - **묶인 항목은 묶은 채로 한 레코드로 둔다.** 한국은행이 대비 개념을 함께 설명하기 때문이다.
    대신 `aliases`에 조각을 담아 검색에서 `복리`로도 찾히게 한다.
  - 숫자를 맞추려고 항목을 쪼개거나 합치거나 지어내지 말 것. 몇 개 빠지는 것은 괜찮고,
    빠진 것을 조용히 덮는 것은 안 된다 — 누락 목록은 `build/missing.txt`에 남긴다.
  - **개수는 느슨하게, 품질은 엄격하게.** 정의 잘림·노이즈 혼입·깨진 연관검색어는
    개수와 무관한 별개 문제이며 여전히 전부 막는다.
- 외부 라이브러리를 추가하지 않는다. npm install, pip install 모두 금지.
- 빌드 단계를 만들지 않는다. `index.html`을 열면 그대로 동작해야 한다.
- 파일 하나가 400줄을 넘으면 쪼갠다.
- 카테고리는 대분류 4개 / 소분류 15개 고정. 미분류를 남기지 않는다.
  - 경제상식: `물가·인플레이션` `경기·경기지표` `성장·국민계정` `재정·조세` `노동·산업`
  - 금융상식: `통화정책` `금융시장` `금융기관·감독` `금융안정·리스크` `지급결제·디지털금융`
  - 국제·외환: `외환·환율` `국제수지·무역` `국제기구·협정`
  - 경영·회계: `회계·재무` `기업경영`
- `status` 값은 `"known"` / `"unknown"` / `null` 세 가지뿐이다.
- 모든 화면 하단에 `자료 출처: 한국은행 『경제금융용어 800선』(2026)`을 고정 노출한다.
- 모든 `localStorage` 접근은 `try/catch`로 감싼다. 저장에 실패해도 앱은 동작해야 한다.
- 폰 화면 폭 360px에서 가로 스크롤이 생기지 않아야 한다.
- Windows 환경이다. Python 스크립트의 파일 입출력은 **반드시 `encoding="utf-8"`을 명시**한다. 생략하면 cp949로 읽혀 한글이 깨진다.

```python
"""PDF에서 텍스트를 추출한다. 페이지 구분은 \\f."""
import subprocess, sys
from pathlib import Path

PDF = Path("2026_경제금융용어 800선.pdf")
OUT = Path("build/full.txt")

def main():
    if not PDF.exists():
        sys.exit(f"PDF를 찾을 수 없습니다: {PDF}")
    OUT.parent.mkdir(exist_ok=True)
    subprocess.run(
        ["pdftotext", "-enc", "UTF-8", str(PDF), str(OUT)],
        check=True,
    )
    text = OUT.read_text(encoding="utf-8")
    pages = text.count("\f")
    print(f"추출 완료: {len(text):,}자, {pages}페이지")
    if pages < 400:
        sys.exit(f"페이지 수가 비정상입니다: {pages} (예상 423)")

if __name__ == "__main__":
    main()
```

- [ ] **Step 3: `tools/toc.py` 구현**

병합 규칙: 점선+페이지번호로 **끝나지 않는** 줄 조각은 다음 줄 맨 앞 제목의 앞부분이다. 꼬리에 붙은 `·` 한 개는 떼어낸다.

```python
"""목차에서 용어 화이트리스트를 추출한다."""
import json, re, sys
from pathlib import Path

# 점선 구분자 + 페이지번호. 이것만 찾고 "구분자 사이의 텍스트"를 이름으로 취한다.
#
# 주의 — 이름 쪽을 정규식으로 표현하려 들지 말 것.
# `((?:[^·\n\f]|·(?!··)){2,60}?)\s*·{3,}\s*(\d+)` 처럼 가운뎃점을 허용하는 교대 반복을 쓰면
# 점선이 없는 본문의 긴 줄에서 매치가 실패할 때 백트래킹이 폭발해 사실상 멈춘다(실측: 2분 초과).
# 구분자만 찾고 사이를 잘라내면 선형 시간이고, 가운뎃점도 자연히 보존된다.
SEP = re.compile(r"·{3,}\s*(\d+)")
NOISE = re.compile(r"^(?:[ㄱ-ㅎ]|[A-Z]|[ivxlIVXL]+|I 경제금융용어 800선|찾아보기.*)$")

def parse_toc(text: str) -> list[tuple[str, int]]:
    start = text.find("찾아보기")
    if start < 0:
        raise ValueError("목차(찾아보기)를 찾을 수 없습니다")

    out: list[tuple[str, int]] = []
    for page in text[start:].split("\f"):
        if not SEP.search(page):
            continue                    # 목차가 아닌 페이지는 건너뛴다
        out.extend(_parse_page(page))
    return out

def _parse_page(page: str) -> list[tuple[str, int]]:
    out: list[tuple[str, int]] = []
    carry = ""                          # 다음 줄로 이어질 제목 앞부분
    for raw in page.split("\n"):
        line = raw.strip()
        if not line or NOISE.match(line):
            continue

        line = carry + line
        carry = ""

        pos = 0
        for m in SEP.finditer(line):
            name = _clean(line[pos:m.start()])
            if name:
                out.append((name, int(m.group(1))))
            pos = m.end()

        # 마지막 구분자 뒤에 남은 꼬리는 다음 줄로 이어지는 제목이다
        tail = line[pos:].strip()
        if tail:
            carry = tail.rstrip("·").strip()
    return out

def _clean(name: str) -> str:
    """앞에 붙은 초성/알파벳 섹션 머리글자와 군더더기를 뗀다."""
    name = name.strip()
    name = re.sub(r"^[ㄱ-ㅎ]\s+", "", name)
    name = re.sub(r"^[A-Z]\s{2,}", "", name)
    return name.strip(" ·")

def main():
    text = Path("build/full.txt").read_text(encoding="utf-8")
    entries = parse_toc(text)
    seen, uniq = set(), []
    for name, page in entries:
        if name not in seen:
            seen.add(name)
            uniq.append({"term": name, "page": page})

    Path("build/toc.json").write_text(
        json.dumps(uniq, ensure_ascii=False, indent=1), encoding="utf-8"
    )
    print(f"목차 항목: {len(uniq)}개 (목표 789)")
    if len(uniq) < 750:
        print(f"너무 적습니다 ({len(uniq)}개). 파싱이 깨진 것으로 보입니다.")
        print("마지막 10개:", [u["term"] for u in uniq[-10:]])
        sys.exit(1)

if __name__ == "__main__":
    main()
```

```python
"""본문에서 용어별 정의를 추출한다."""
import json, re, sys
from pathlib import Path

HEADER = "I 경제금융용어 800선"
PAGE_NO = re.compile(r"^\d{1,3}$")
CHOSUNG_ONLY = re.compile(r"^[ㄱ-ㅎ]$")
RELATED = re.compile(r"^연관검색어\s*(.+)$", re.M)
# 문장이 끝났다고 볼 수 있는 꼬리
CLOSED = re.compile(r"[.)%\d]$|다$")

def clean_lines(page_text: str, running_heads: set[str] | None = None) -> list[str]:
    lines = [ln.strip() for ln in page_text.split("\n")]
    out = []
    for i, ln in enumerate(lines):
        if not ln or ln == HEADER or PAGE_NO.match(ln) or CHOSUNG_ONLY.match(ln):
            continue
        # 페이지 첫 유효 줄이 용어명이면 러닝 헤드다
        if not out and running_heads and ln in running_heads:
            continue
        out.append(ln)
    return out

def join_wrapped(lines: list[str]) -> str:
    if not lines:
        return ""
    buf = [lines[0]]
    for ln in lines[1:]:
        if CLOSED.search(buf[-1]):
            buf.append(ln)          # 앞 줄이 끝났으면 새 조각
        else:
            buf[-1] = buf[-1] + " " + ln   # 안 끝났으면 이어 붙인다
    return " ".join(buf)

def split_related(body: str) -> tuple[str, list[str]]:
    m = RELATED.search(body)
    if not m:
        return body.strip(), []
    related = [t.strip() for t in m.group(1).split(",") if t.strip()]
    definition = (body[: m.start()] + body[m.end() :]).strip()
    return definition, related

def extract(text: str, toc: list[dict]) -> list[dict]:
    """목차를 정답지로 삼아 본문을 용어 단위로 자른다."""
    names = {e["term"]: e["page"] for e in toc}
    pages = text.split("\f")

    # (용어명, 등장 페이지, 전체 줄 목록에서의 위치)를 찾는다
    flat: list[tuple[str, int]] = []   # (줄, 페이지번호)
    for pno, page in enumerate(pages, start=1):
        for ln in clean_lines(page, running_heads=set(names)):
            flat.append((ln, pno))

    # 본문 시작점: 첫 용어가 단독 줄로 나오는 곳
    first = toc[0]["term"]
    start = next(i for i, (ln, _) in enumerate(flat) if ln == first)

    # 용어 경계 탐지 — 이름이 단독 줄이고 목차 페이지와 가까울 때만
    marks: list[tuple[int, str]] = []
    offset = None
    for i in range(start, len(flat)):
        ln, pno = flat[i]
        if ln not in names:
            continue
        if offset is None:
            offset = pno - names[ln]      # 본문 쪽수와 인쇄 쪽수의 차이
        if abs((pno - offset) - names[ln]) <= 1:
            marks.append((i, ln))

    # 같은 용어가 여러 번 걸리면 첫 등장만 남긴다
    seen, uniq_marks = set(), []
    for i, name in marks:
        if name not in seen:
            seen.add(name)
            uniq_marks.append((i, name))

    out = []
    for k, (i, name) in enumerate(uniq_marks):
        end = uniq_marks[k + 1][0] if k + 1 < len(uniq_marks) else len(flat)
        body = join_wrapped([ln for ln, _ in flat[i + 1 : end]])
        definition, related = split_related(body)
        out.append({
            "term": name,
            "def": definition,
            "related": related,
            "page": names[name],
        })
    return out

def main():
    text = Path("build/full.txt").read_text(encoding="utf-8")
    toc = json.loads(Path("build/toc.json").read_text(encoding="utf-8"))
    terms = extract(text, toc)

    Path("build/raw_terms.json").write_text(
        json.dumps(terms, ensure_ascii=False, indent=1), encoding="utf-8"
    )
    print(f"추출: {len(terms)}개 / 목차 {len(toc)}개")

    # 누락은 기록만 하고 통과시킨다 — 개수는 느슨하게
    missing = sorted({e["term"] for e in toc} - {t["term"] for t in terms})
    Path("build/missing.txt").write_text("\n".join(missing), encoding="utf-8")
    if missing:
        print(f"누락 {len(missing)}개 (build/missing.txt에 기록):", missing[:10])
    if len(terms) < 750:
        print(f"추출이 너무 적습니다: {len(terms)}개")
        sys.exit(1)

    # 품질은 엄격하게 — 정의가 잘린 것은 개수와 무관한 문제다
    short = [t["term"] for t in terms if len(t["def"]) < 50]
    if short:
        print(f"정의가 짧은 항목 {len(short)}개:", short[:20])
        sys.exit(1)

if __name__ == "__main__":
    main()
```

```python
"""용어 레코드 스키마 조립."""
import re

CHO = list("ㄱㄲㄴㄷㄸㄹㅁㅂㅃㅅㅆㅇㅈㅉㅊㅋㅌㅍㅎ")
HANGUL_BASE = 0xAC00
HANGUL_LAST = 0xD7A3

def chosung(s: str) -> str:
    out = []
    for ch in s:
        code = ord(ch)
        if HANGUL_BASE <= code <= HANGUL_LAST:
            out.append(CHO[(code - HANGUL_BASE) // 588])
    return "".join(out)

def extract_alt(term: str, definition: str) -> str | None:
    # 1순위: 용어명 자체의 괄호 안 약어
    m = re.search(r"\(([A-Za-z][A-Za-z0-9 .;/&-]{1,40})\)", term)
    if m:
        return m.group(1).strip()
    # 2순위: 정의 첫머리에서 "용어명(English)" 형태
    head = definition[:120]
    m = re.search(r"\(([A-Za-z][A-Za-z0-9 .;/&-]{2,40})\)", head)
    if m:
        return m.group(1).strip()
    return None

def split_aliases(term: str) -> list[str]:
    """'단리/복리'처럼 묶인 표제어를 조각낸다. 레코드는 쪼개지 않고 검색용으로만 쓴다."""
    if "/" not in term:
        return []
    return [p.strip() for p in term.split("/") if p.strip()]

def build_record(raw: dict) -> dict:
    term = raw["term"]
    return {
        "id": term,
        "term": term,
        "alt": extract_alt(term, raw["def"]),
        "aliases": split_aliases(term),
        "chosung": chosung(term),
        "def": raw["def"],
        "related": raw["related"],
        "category": None,       # Task 5에서 채운다
        "subcategory": None,
        "page": raw["page"],
    }
```

```python
def _score(term: str, text: str) -> Counter:
    scores = Counter()
    for sub, (_cat, keywords) in SUBCATEGORIES.items():
        s = 0
        for kw in keywords:
            s += term.count(kw) * TERM_WEIGHT
            s += text.count(kw)
        if s:
            scores[sub] = s
    return scores

def classify(term: str, definition: str) -> tuple[str, str]:
    scores = _score(term, definition[:400])
    if not scores:
        return FALLBACK

    top = scores.most_common()
    if len(top) > 1 and top[0][1] == top[1][1]:
        # 동점이면 첫 문장만으로 다시 매긴다
        first = definition.split(".")[0]
        tie = {s for s, v in top if v == top[0][1]}
        refined = _score(term, first)
        narrowed = [(s, v) for s, v in refined.most_common() if s in tie]
        if narrowed:
            sub = narrowed[0][0]
        else:
            sub = sorted(tie)[0]
    else:
        sub = top[0][0]

    return SUBCATEGORIES[sub][0], sub

    for rec in raw:
        cat, sub = classify(rec["term"], rec["def"])
        rec["category"], rec["subcategory"] = cat, sub

    Path("data").mkdir(exist_ok=True)
    Path("data/terms.json").write_text(
        json.dumps(raw, ensure_ascii=False, indent=1), encoding="utf-8"

    by_cat = Counter(r["category"] for r in raw)
    by_sub = Counter(r["subcategory"] for r in raw)
    print(f"분류 완료: {len(raw)}개")
    for cat, n in by_cat.most_common():
        print(f"  {cat:8s} {n:4d}")
    empty = set(SUBCATEGORIES) - set(by_sub)
    if empty:
        print("비어 있는 소분류:", sorted(empty))

if __name__ == "__main__":
    main()
```

```python
import json, re, sys
from collections import Counter
from pathlib import Path

VALID = {
    "경제상식": {"물가·인플레이션", "경기·경기지표", "성장·국민계정", "재정·조세", "노동·산업"},

    "경영·회계": {"회계·재무", "기업경영"},
}
NOISE = ["경제금융용어 800선"]
END_OK = re.compile(r"[.)%\d]$|다$")

def check(terms: list[dict]) -> list[str]:
    errors = []

    # 개수는 느슨하게 — 하한만 본다
    if len(terms) < 750:
        errors.append(f"용어 수가 하한 750 미만: {len(terms)}")

    ids = [t["id"] for t in terms]
    dupes = [i for i, n in Counter(ids).items() if n > 1]
    if dupes:
        errors.append(f"id 중복 {len(dupes)}건: {dupes[:10]}")

    id_set = set(ids)
    for t in terms:
        term, d = t["term"], t["def"]

        if len(d) < 50:
            errors.append(f"[{term}] 정의가 50자 미만: {len(d)}자")
        for n in NOISE:
            if n in d:
                errors.append(f"[{term}] 정의에 노이즈 '{n}' 포함")
        if re.search(r"(^|\s)\d{1,3}(\s|$)", d) and re.search(r"\n\d{1,3}\n", d):
            errors.append(f"[{term}] 정의에 단독 숫자 줄 포함")
        if re.search(r"(^|\s)[ㄱ-ㅎ](\s|$)", d):
            errors.append(f"[{term}] 정의에 단독 초성 포함")
        if not END_OK.search(d.strip()):
            errors.append(f"[{term}] 정의가 어미 중간에서 끊김: …{d[-25:]!r}")

        for r in t["related"]:
            if r not in id_set:
                errors.append(f"[{term}] related '{r}'가 존재하지 않는 id")

        cat, sub = t["category"], t["subcategory"]
        if cat not in VALID:
            errors.append(f"[{term}] 알 수 없는 대분류: {cat}")
        elif sub not in VALID[cat]:
            errors.append(f"[{term}] 대분류 {cat}에 없는 소분류: {sub}")

        if not t["chosung"]:
            errors.append(f"[{term}] 초성이 비어 있음")

        if "/" in term and not t["aliases"]:
            errors.append(f"[{term}] 묶음 표제어인데 aliases가 비어 있음")

    return errors

def main():
    terms = json.loads(Path("data/terms.json").read_text(encoding="utf-8"))
    errors = check(terms)

    if errors:
        print(f"검증 실패 — {len(errors)}건")
        for e in errors[:40]:
            print("  ", e)
        if len(errors) > 40:
            print(f"   … 외 {len(errors) - 40}건")
        sys.exit(1)

    print(f"검증 통과 — {len(terms)}개")
    by_cat = Counter(t["category"] for t in terms)
    for cat, n in by_cat.most_common():
        print(f"  {cat:8s} {n:4d}")

if __name__ == "__main__":
    main()
```

```js
// 학습 기록 저장소. localStorage 접근은 전부 여기를 거친다.

const KEYS = {
  progress: "econ.progress",
  session: "econ.session",
  prefs: "econ.prefs",
};

const EMPTY = { status: null, starred: false, seen: 0, wrong: 0, at: 0 };

function memoryBackend() {
  const map = new Map();
  return {
    getItem: (k) => (map.has(k) ? map.get(k) : null),
    setItem: (k, v) => map.set(k, String(v)),
    removeItem: (k) => map.delete(k),
  };
}

function pickBackend(given) {
  if (given) return given;
  try {
    const probe = "__econ_probe__";
    globalThis.localStorage.setItem(probe, "1");
    globalThis.localStorage.removeItem(probe);
    return globalThis.localStorage;
  } catch {
    return memoryBackend();   // 사생활 보호 모드 등
  }
}

export function createStore(backend) {
  const store = pickBackend(backend);

  const read = (key, fallback) => {
    try {
      const raw = store.getItem(key);
      return raw ? JSON.parse(raw) : fallback;
    } catch {
      return fallback;
    }
  };

  const write = (key, value) => {
    try {
      store.setItem(key, JSON.stringify(value));
      return true;
    } catch {
      return false;   // 저장에 실패해도 앱은 계속 간다
    }
  };

  const mutate = (id, fn) => {
    const all = read(KEYS.progress, {});
    const entry = { ...EMPTY, ...(all[id] || {}) };
    fn(entry);
    entry.at = Date.now();
    all[id] = entry;
    write(KEYS.progress, all);
    return entry;
  };

  return {
    getProgress(id) {
      return { ...EMPTY, ...(read(KEYS.progress, {})[id] || {}) };
    },
    getAllProgress() {
      return read(KEYS.progress, {});
    },
    setStatus(id, status) {
      return mutate(id, (e) => { e.status = status; });
    },
    toggleStar(id) {
      return mutate(id, (e) => { e.starred = !e.starred; }).starred;
    },
    recordQuiz(id, correct) {
      // status는 건드리지 않는다 — 외움/안외움은 사용자가 정한다
      return mutate(id, (e) => {
        e.seen += 1;
        if (!correct) e.wrong += 1;
      });
    },

    getSession() {
      return read(KEYS.session, null);
    },
    setSession(session) {
      write(KEYS.session, session);
    },
    clearSession() {
      try { store.removeItem(KEYS.session); } catch { /* 무시 */ }
    },

    getPrefs() {
      return read(KEYS.prefs, {});
    },
    setPrefs(prefs) {
      write(KEYS.prefs, prefs);
    },

    exportAll() {
      return JSON.stringify({
        version: 1,
        exportedAt: new Date().toISOString(),
        progress: read(KEYS.progress, {}),
        prefs: read(KEYS.prefs, {}),
      }, null, 1);
    },
    importAll(json) {
      let data;
      try {
        data = JSON.parse(json);
      } catch {
        return false;
      }
      if (!data || typeof data.progress !== "object" || data.progress === null) {
        return false;
      }
      write(KEYS.progress, data.progress);
      if (data.prefs) write(KEYS.prefs, data.prefs);
      return true;
    },
    clearAll() {
      for (const k of Object.values(KEYS)) {
        try { store.removeItem(k); } catch { /* 무시 */ }
      }
    },
  };
}

export const store = createStore();
```

```js
import { store } from "./store.js";

let TERMS = [];
const views = new Map();

export function registerView(name, renderFn) {
  views.set(name, renderFn);
}

export function getTerms() {
  return TERMS;
}

export function getTerm(id) {
  return TERMS.find((t) => t.id === id) || null;
}

export function navigate(view, params = {}) {
  const qs = new URLSearchParams(params).toString();
  location.hash = `#/${view}${qs ? "?" + qs : ""}`;
}

function parseHash() {
  const raw = location.hash.slice(2) || "home";
  const [view, qs] = raw.split("?");
  return { view, params: Object.fromEntries(new URLSearchParams(qs || "")) };
}

function render() {
  const { view, params } = parseHash();
  const container = document.getElementById("view");
  const renderFn = views.get(view) || views.get("home");

  container.innerHTML = "";
  document.getElementById("back").hidden = view === "home";
  renderFn(container, params);
}

function renderHome(container) {
  const progress = store.getAllProgress();
  const known = TERMS.filter((t) => progress[t.id]?.status === "known").length;
  const pct = Math.round((known / TERMS.length) * 100);

  const session = store.getSession();
  const resume = session && session.cursor < session.ids.length;

  const byCat = {};
  for (const t of TERMS) {
    byCat[t.category] ??= { total: 0, known: 0 };
    byCat[t.category].total += 1;
    if (progress[t.id]?.status === "known") byCat[t.category].known += 1;
  }

  container.innerHTML = `
    <p><strong>${known}</strong> / ${TERMS.length} 외움 (${pct}%)</p>
    <div class="progress-bar"><div class="progress-fill" style="width:${pct}%"></div></div>
    ${Object.entries(byCat).map(([cat, v]) => `
      <p style="margin:12px 0 4px;font-size:13px">${cat} — ${v.known}/${v.total}</p>
      <div class="progress-bar"><div class="progress-fill"
           style="width:${Math.round((v.known / v.total) * 100)}%"></div></div>
    `).join("")}
    <div class="home-actions">
      <button class="primary" data-go="session">
        ${resume ? `이어하기 (${session.cursor}/${session.ids.length})` : "오늘의 학습 20개 시작"}
      </button>
      <button data-go="list">용어장</button>
      <button data-go="quiz" data-mode="ox">OX 퀴즈</button>
      <button data-go="quiz" data-mode="choice">용어 맞히기</button>
      <button data-go="stats">통계</button>
    </div>
  `;

  container.querySelectorAll("[data-go]").forEach((btn) => {
    btn.addEventListener("click", () => {
      const params = btn.dataset.mode ? { mode: btn.dataset.mode } : {};
      navigate(btn.dataset.go, params);
    });
  });
}

async function boot() {
  try {
    const res = await fetch("data/terms.json");
    TERMS = await res.json();
  } catch {
    document.getElementById("view").innerHTML =
      `<p>용어 데이터를 불러오지 못했습니다. 로컬 파일로 열었다면
       <code>python -m http.server</code>로 띄워 주세요.</p>`;
    return;
  }

  registerView("home", renderHome);
  // 나머지 화면은 Task 9 이후 각 모듈에서 registerView로 등록한다
  const modules = await Promise.all([
    import("./list.js").catch(() => null),
    import("./session.js").catch(() => null),
    import("./quiz-ui.js").catch(() => null),
    import("./stats.js").catch(() => null),
  ]);
  for (const m of modules) m?.init?.();

  window.addEventListener("hashchange", render);
  document.getElementById("back").addEventListener("click", () => navigate("home"));
  render();
}

boot();
```

```js
// 용어 필터링. 순수 함수이며 DOM을 모른다.

export function filterTerms(terms, progress, criteria = {}) {
  const { q, category, subcategory, status, starred, chosung } = criteria;
  const needle = (q || "").trim().toLowerCase();

  return terms.filter((t) => {
    const p = progress[t.id] || {};

    if (category && t.category !== category) return false;
    if (subcategory && t.subcategory !== subcategory) return false;

    if (status === "known" && p.status !== "known") return false;
    if (status === "unknown" && p.status !== "unknown") return false;
    if (status === "none" && p.status) return false;

    if (starred && !p.starred) return false;

    if (chosung && !t.chosung.startsWith(chosung)) return false;

    if (needle) {
      // aliases 덕분에 "단리/복리" 카드가 "복리" 검색에도 걸린다
      const hay = [t.term, t.chosung, t.alt || "", ...(t.aliases || []), t.def]
        .join(" ").toLowerCase();
      if (!hay.includes(needle)) return false;
    }
    return true;
  });
}
```

```js
import { registerView, getTerms, getTerm, navigate } from "./app.js";
import { store } from "./store.js";

const PAGE = 50;
const CATEGORIES = {

function renderList(container, params) {
  const criteria = { ...store.getPrefs().filters, ...params };
  let shown = PAGE;

  container.innerHTML = `

    <p id="count"></p>
    <ul id="items"></ul>
    <button id="more" hidden>더 보기</button>
  `;

  const draw = () => {
    const progress = store.getAllProgress();
    const hits = filterTerms(getTerms(), progress, criteria);
    container.querySelector("#count").textContent = `${hits.length}개`;

    const items = container.querySelector("#items");

      const p = progress[t.id] || {};

        <button class="star" aria-pressed="${!!p.starred}">${p.starred ? "★" : "☆"}</button>

    if (e.target.classList.contains("known")) {
      const cur = store.getProgress(id).status;
      store.setStatus(id, cur === "known" ? "unknown" : "known");
      draw();
    }
  });

  renderChips(container.querySelector("#chips"), criteria, () => { shown = PAGE; draw(); });
  draw();
}

function renderChips(host, criteria, onChange) {
  const set = (key, value) => {
    criteria[key] = criteria[key] === value ? undefined : value;
    if (key === "category") criteria.subcategory = undefined;
    host.innerHTML = "";
    renderChips(host, criteria, onChange);
    onChange();
  };

  const row = (label, key, values) => {
    const div = document.createElement("div");
    div.className = "chip-row";
    div.innerHTML = `<span class="chip-label">${label}</span>` +
      values.map((v) =>
        `<button class="chip" aria-pressed="${criteria[key] === v.value}" data-v="${v.value}">${v.label}</button>`
      ).join("");
    div.addEventListener("click", (e) => {
      const btn = e.target.closest(".chip");
      if (btn) set(key, btn.dataset.v);
    });
    host.appendChild(div);
  };

  row("대분류", "category", Object.keys(CATEGORIES).map((c) => ({ label: c, value: c })));
  if (criteria.category) {
    row("소분류", "subcategory", CATEGORIES[criteria.category].map((s) => ({ label: s, value: s })));
  }
  row("상태", "status", [
    { label: "외움", value: "known" },
    { label: "안외움", value: "unknown" },
    { label: "미학습", value: "none" },
  ]);
  row("중요", "starred", [{ label: "중요만", value: "1" }]);
  row("초성", "chosung", [..."ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ"].map((c) => ({ label: c, value: c })));
}

function renderTerm(container, { id }) {
  const t = getTerm(id);
  if (!t) { container.innerHTML = "<p>용어를 찾을 수 없습니다.</p>"; return; }
  const p = store.getProgress(id);

  container.innerHTML = `
    <h2>${t.term}</h2>
    ${t.alt ? `<p class="alt">${t.alt}</p>` : ""}
    <p class="sub">${t.category} · ${t.subcategory} · ${t.page}쪽</p>
    <p class="def">${t.def}</p>
    ${t.related.length ? `<p class="related">연관 ${t.related.map((r) =>
      `<button data-rel="${r}">${r}</button>`).join(" ")}</p>` : ""}
    <div class="term-actions">
      <button id="t-known" aria-pressed="${p.status === "known"}">
        ${p.status === "known" ? "외움 ●" : "외움으로 표시"}
      </button>
      <button id="t-star" aria-pressed="${p.starred}">${p.starred ? "중요 ★" : "중요 표시"}</button>
    </div>
  `;

  container.querySelector("#t-known").addEventListener("click", () => {
    const cur = store.getProgress(id).status;
    store.setStatus(id, cur === "known" ? "unknown" : "known");
    renderTerm(container, { id });
  });
  container.querySelector("#t-star").addEventListener("click", () => {
    store.toggleStar(id);
    renderTerm(container, { id });
  });
  container.querySelectorAll("[data-rel]").forEach((b) =>
    b.addEventListener("click", () => navigate("term", { id: b.dataset.rel })));
}

export function init() {
```

```js
import { registerView, getTerms, getTerm, navigate } from "./app.js";
import { store } from "./store.js";

const SIZE = 20;

function pickIds() {
  const progress = store.getAllProgress();
  const fresh = [], weak = [];
  for (const t of getTerms()) {
    const s = progress[t.id]?.status;
    if (!s) fresh.push(t.id);
    else if (s === "unknown") weak.push(t.id);
  }
  return [...fresh, ...weak].slice(0, SIZE);
}

function renderSession(container) {
  let session = store.getSession();
  if (!session || session.cursor >= session.ids.length) {
    const ids = pickIds();
    if (ids.length === 0) {
      container.innerHTML = `<p>외울 용어가 남아 있지 않습니다. 훌륭합니다.</p>
        <button id="home">홈으로</button>`;
      container.querySelector("#home").addEventListener("click", () => navigate("home"));
      return;
    }
    session = { ids, cursor: 0, startedAt: Date.now() };
    store.setSession(session);
  }
  drawCard(container, session);
}

function drawCard(container, session) {
  const id = session.ids[session.cursor];
  const t = getTerm(id);

  container.innerHTML = `
    <p class="sub">오늘의 학습 ${session.cursor + 1} / ${session.ids.length}</p>
    <div class="card">
      <h2>${t.term}</h2>
      <p class="def" id="def" hidden>${t.def}</p>
      <button id="reveal">뜻 보기</button>
    </div>
    <div class="card-actions" hidden id="actions">
      <button id="no">모르겠음</button>
      <button id="yes">외웠음</button>
    </div>
  `;

  container.querySelector("#reveal").addEventListener("click", (e) => {
    container.querySelector("#def").hidden = false;
    container.querySelector("#actions").hidden = false;
    e.target.hidden = true;
  });

  const advance = (status) => {
    store.setStatus(id, status);
    const next = { ...session, cursor: session.cursor + 1 };
    store.setSession(next);

    if (next.cursor >= next.ids.length) {
      store.clearSession();
      navigate("quiz", { mode: "review", ids: next.ids.join(",") });
    } else {
      drawCard(container, next);
    }
  };

  container.querySelector("#no").addEventListener("click", () => advance("unknown"));
  container.querySelector("#yes").addEventListener("click", () => advance("known"));
}

export function init() {
  registerView("session", renderSession);
}
```

```js
// 퀴즈 문항 생성. 순수 함수이며 DOM을 모른다.

const ANTONYMS = [
  ["상승", "하락"], ["증가", "감소"], ["확대", "축소"], ["완화", "긴축"],
  ["인상", "인하"], ["매입", "매각"], ["흑자", "적자"], ["상향", "하향"],
  ["강화", "약화"], ["호황", "불황"], ["초과", "미달"], ["유입", "유출"],
  // 어미를 붙여 부분 문자열 오치환을 막는다 ("높이"가 "낮이"가 되면 안 된다)
  ["높아", "낮아"], ["높은", "낮은"], ["높다", "낮다"],
  ["커지", "작아지"], ["늘어", "줄어"],
];

// 바꾸면 안 되는 숫자: 연도, 바젤 III, G20, COVID-19
const PROTECTED_NUM = /\d{4}년|바젤\s*[IVX]+|G\d{1,2}|COVID-\d+/g;

export function pickSentence(def) {
  const sentences = def
    .split(/(?<=다\.)\s*/)
    .map((s) => s.trim())
    .filter((s) => s.length >= 30 && s.length <= 120);
  return sentences.length ? sentences[0] : null;
}

export function flipAntonym(sentence) {
  for (const [a, b] of ANTONYMS) {
    if (sentence.includes(a)) {
      return { text: sentence.replace(a, b), from: a, to: b };
    }
    if (sentence.includes(b)) {
      return { text: sentence.replace(b, a), from: b, to: a };
    }
  }
  return null;
}

export function perturbNumber(sentence, rng = Math.random) {
  // 보호 대상을 자리표시자로 가린 뒤 후보를 찾는다
  const guarded = sentence.replace(PROTECTED_NUM, (m) => "\u0000".repeat(m.length));
  const matches = [...guarded.matchAll(/\d+/g)];
  if (!matches.length) return null;

  const m = matches[Math.floor(rng() * matches.length)];
  const original = m[0];
  const value = Number(original);

  // 원래 값과 충분히 다른 값을 만든다 (±10% 이내 금지)
  const factors = [0.5, 1.5, 2, 3];
  const factor = factors[Math.floor(rng() * factors.length)];
  let replaced = Math.max(1, Math.round(value * factor));
  if (replaced === value) replaced = value + Math.max(1, Math.round(value * 0.5));

  const text =
    sentence.slice(0, m.index) + String(replaced) + sentence.slice(m.index + original.length);
  return { text, from: original, to: String(replaced) };
}

export function crossDefinition(term, pool, rng = Math.random) {
  const byId = new Map(pool.map((t) => [t.id, t]));
  const tiers = [
    term.related.map((r) => byId.get(r)).filter(Boolean),
    pool.filter((t) => t.id !== term.id && t.subcategory === term.subcategory),
    pool.filter((t) => t.id !== term.id && t.category === term.category),
  ];

  for (const tier of tiers) {
    const usable = tier.filter((t) => pickSentence(t.def));
    if (usable.length) {
      const other = usable[Math.floor(rng() * usable.length)];
      const sentence = pickSentence(other.def);
      return {
        text: `${term.term}(이)란 ${sentence.replace(/^.*?(이란|란|은|는)\s*/, "")}`,
        source: other.term,
      };
    }
  }
  return null;
}

export function makeOX(term, pool, rng = Math.random) {
  const sentence = pickSentence(term.def);
  if (!sentence) return null;

  // 참 문항
  if (rng() < 0.5) {
    return {
      termId: term.id,
      statement: sentence,
      answer: true,
      explain: `${term.term}의 설명 그대로입니다.`,
    };
  }

  // 거짓 문항 — 규칙 1·2를 규칙 3보다 우선한다
  const flipped = flipAntonym(sentence);
  if (flipped) {
    return {
      termId: term.id,
      statement: flipped.text,
      answer: false,
      explain: `원문은 '${flipped.from}'입니다.`,
    };
  }

  const perturbed = perturbNumber(sentence, rng);
  if (perturbed) {
    return {
      termId: term.id,
      statement: perturbed.text,
      answer: false,
      explain: `원문은 '${perturbed.from}'입니다.`,
    };
  }

  const crossed = crossDefinition(term, pool, rng);
  if (crossed) {
    return {
      termId: term.id,
      statement: crossed.text,
      answer: false,
      explain: `'${crossed.source}'의 설명입니다.`,
    };
  }

  return null;   // 억지로 만들지 않는다
}
```

```js
export function maskTerm(def, term, alt) {
  const mask = "○".repeat(Math.min(Math.max(term.length, 2), 5));
  let out = def.split(term).join(mask);
  if (alt) out = out.split(alt).join("○○○");
  return out;
}

export function makeChoice(term, pool, rng = Math.random) {
  const sentence = pickSentence(term.def) || term.def.slice(0, 120);
  if (!sentence) return null;

  // 오답은 같은 소분류에서, 모자라면 같은 대분류로 넓힌다
  const sameSub = pool.filter((t) => t.id !== term.id && t.subcategory === term.subcategory);
  const sameCat = pool.filter((t) => t.id !== term.id && t.category === term.category);
  const candidates = sameSub.length >= 3 ? sameSub : sameCat;
  if (candidates.length < 3) return null;

  // 후보를 섞은 뒤 앞에서 3개를 집는다.
  // rng가 상수를 돌려줘도 끝나야 하므로 무작위 추첨 루프를 쓰지 않는다.
  const shuffled = [...candidates];
  for (let i = shuffled.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [shuffled[i], shuffled[j]] = [shuffled[j], shuffled[i]];
  }

  const used = new Set([term.term]);
  const picked = [];
  for (const c of shuffled) {
    if (picked.length >= 3) break;
    if (!used.has(c.term)) {
      used.add(c.term);
      picked.push(c.term);
    }
  }
  if (picked.length < 3) return null;

  const options = [term.term, ...picked];
  // 결정적으로 섞는다
  for (let i = options.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [options[i], options[j]] = [options[j], options[i]];
  }

  return {
    termId: term.id,
    question: maskTerm(sentence, term.term, term.alt),
    options,
    answer: term.term,
  };
}
```

```js
function buildQuestions(mode, params) {
  const all = getTerms();

  if (mode === "review") {
    const ids = (params.ids || "").split(",").filter(Boolean);
    const subset = ids.map(getTerm).filter(Boolean);
    return [
      ...subset.slice(0, 10).map((t) => makeOX(t, all)).filter(Boolean),
      ...subset.slice(10).map((t) => makeChoice(t, all)).filter(Boolean),
    ];
  }

  const progress = store.getAllProgress();
  let pool = all;
  if (params.scope === "unknown") pool = all.filter((t) => progress[t.id]?.status !== "known");
  if (params.scope === "starred") pool = all.filter((t) => progress[t.id]?.starred);
  if (params.category) pool = pool.filter((t) => t.category === params.category);

  const count = Number(params.count || 10);
  const make = mode === "ox" ? makeOX : makeChoice;
  const shuffled = [...pool].sort(() => Math.random() - 0.5);

  const out = [];
  for (const t of shuffled) {
    if (out.length >= count) break;
    const q = make(t, all);
    if (q) out.push(q);
  }
  return out;
}

function renderQuiz(container, params) {
  const mode = params.mode || "ox";
  const questions = buildQuestions(mode, params);

  if (!questions.length) {
    container.innerHTML = `<p>출제할 문항이 없습니다.</p><button id="home">홈으로</button>`;
    container.querySelector("#home").addEventListener("click", () => navigate("home"));
    return;
  }

  let index = 0, correct = 0;
  const wrongIds = [];

  const draw = () => {
    const q = questions[index];
    const isOX = "answer" in q && typeof q.answer === "boolean";

    container.innerHTML = `
      <p class="sub">${index + 1} / ${questions.length}</p>

      </div>
      <div id="feedback" hidden></div>
    `;

      btn.addEventListener("click", () => answer(btn.dataset.v, q, isOX))
    );

  const answer = (given, q, isOX) => {
    const right = isOX ? String(q.answer) === given : q.answer === given;
    if (right) correct++;
    else wrongIds.push(q.termId);
    store.recordQuiz(q.termId, right);

      else finish();

      <p class="sub">${Math.round((correct / questions.length) * 100)}%</p>

          `<li><button data-id="${id}">${getTerm(id).term}</button></li>`).join("")
      }</ul>` : "<p>전부 맞혔습니다.</p>"}

      <button id="home">홈으로</button>

    container.querySelector("#home").addEventListener("click", () => navigate("home"));
  };

  draw();
```

```bash
import struct, zlib
def png(path, size, rgb):
    raw = b"".join(b"\x00" + bytes(rgb) * size for _ in range(size))
    def chunk(tag, data):
        c = tag + data
        return struct.pack(">I", len(data)) + c + struct.pack(">I", zlib.crc32(c))
```

## 배포 참고 (Claude 담당)

Artifact와 Orca 공개 링크는 **자체 완결 HTML 한 장**이어야 한다. 상대 경로 asset이 업로드되지 않기 때문이다. 발행 시 다음을 하나로 묶는다.

- `css/style.css` → `<style>`로 인라인
- `js/*.js` → `<script type="module">`로 인라인 (import 구문은 제거하고 하나의 스코프로 병합)
- `data/terms.json` → `const TERMS = [...]` 상수로 인라인, `fetch` 호출 제거

`terms.json`이 대략 1.5~2MB로 예상되므로 16MB 제한에는 여유가 있다. 번들 스크립트를 만들지 말고 Claude가 발행 시점에 한 번 조립한다 — 빌드 단계를 만들지 않는다는 제약을 지키기 위해서다.
